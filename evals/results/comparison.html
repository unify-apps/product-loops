09What changed in the plugin

    10Method and limits

    This measures the intake, the one turn a person actually reads before leaving, on 10 realistic asks per loop. Both versions ran as fresh sessions on the same model with the same files. The script checks are pattern based; read the evidence on a case before trusting a single number. The blind grader is one model reading once. The end-to-end runs are one per loop and prove the machinery, not the quality of a long build. Headless Claude was not signed in on this machine, so runs went through helper agents in one session rather than separate processes, which means the plugin's hooks did not fire during the intake runs; the engine tests cover the hooks.
